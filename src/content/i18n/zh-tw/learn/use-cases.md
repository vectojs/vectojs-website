## 資料視覺化與儀表板

圖表、拓撲檢視器、追蹤和即時儀表板通常需要數百或數千個動畫基本元素。VectoJS 將視覺實體保留在 JavaScript 中，避免為每個點、行或邊建立一個帶樣式的 DOM 節點。

適合的場景：

- 金融訂單簿；
- Kubernetes 拓撲檢視器；
- 即時網路圖；
- 監控追蹤和時間線；
- 高頻分析表面。

## 串流 UI

LLM 客戶端、彈幕、事件動態和即時聊天受益於增量布局和畫布渲染。`RichText.appendSpans()` 和 `Markdown.appendMarkdown()` 讓應用程式可以附加串流內容，而無需從頭重建每個可見物件。

適合的場景：

- AI 聊天客戶端；
- 影片評論覆蓋層；
- 即時日誌和事件動態；
- 包含程式碼、表格和圖表的串流 Markdown。

## 無限畫布與圖形

白板、節點編輯器和知識圖需要平移/縮放、自訂命中測試和剔除。VectoJS 提供場景圖和渲染/事件模型；應用程式可以為非常大的資料集添加自己的索引策略。

適合的場景：

- 協作白板；
- 心智圖和知識圖；
- 節點編輯器；
- 時間線和圖表工具。

## 遊戲與互動媒體

`update(dt)`、動畫驅動器、粒子系統和自訂實體對於瀏覽器原生遊戲和教育模擬非常有用，而無需採用完整的遊戲引擎。

適合的場景：

- 節奏/類遊戲互動；
- 物理沙盒；
- 解說動畫；
- 互動課程教材。

## 編輯器與開發者工具

基於畫布的編輯器需要對文字、選取視覺效果、游標、迷你地圖和覆蓋層進行明確控制。VectoJS 可以提供視覺執行環境，而原生 `Input`/`TextArea` 元件則在需要的地方保留瀏覽器編輯行為。

適合的場景：

- Diff 檢視器；
- 終端機風格表面；
- 豐富的畫布編輯器；
- 追蹤/日誌工具。

## WebXR 與 3D 介面

`@vectojs/three` 將 VectoJS 場景渲染到 `THREE.CanvasTexture` 上，然後將光線投射 UV 映射回 2D 場景。這使得即時 VectoJS 面板能夠在 Three.js 和 WebXR 中使用。

適合的場景：

- 世界內控制項；
- VR/AR 儀表板；
- 儀器面板；
- 空間開發者工具。

## 進階互動網站

VectoJS 可以驅動網站中需要物理、粒子場、磁性排版、生成藝術或客製化互動的部分。將周圍的文件結構保留在 HTML/CSS 中，只在場景模型能夠發揮價值的地方嵌入 VectoJS。

## 適用性檢查清單

如果大多數答案為「是」，請使用 VectoJS：

- UI 是否包含許多移動或需要個別命中測試的物件？
- 是否需要數學定義的布局或變換？
- 是否需要畫布/WebGL/WebGPU 渲染？
- 是否仍然需要無障礙和基於角色的自動化？
- DOM/CSS 布局是否會成為瓶頸或錯誤的抽象層？

如果大多數答案為「否」，請從 HTML/CSS 和傳統應用框架開始。
