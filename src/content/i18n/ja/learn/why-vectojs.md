# Why VectoJS

ブラウザのDOMは、強力な汎用ドキュメントレンダラーです。流し込みテキスト、SEOコンテンツ、ネイティブフォーム、そして中程度のインタラクティブUIには最適です。

しかし、インターフェースがドキュメントよりもシーンのように振る舞うようになると、ボトルネックになります。

## 問題

VectoJSは、次のようなインターフェースを対象としています：

- 何千もの個別にアニメーションする項目が、過剰なDOM/スタイル/レイアウト処理を生み出してしまう；
- レイアウトがCSSのフローではなく数学によって制御される；
- hit-testingがカスタム変換、曲線、座標系に一致しなければならない；
- 同じUIをキャンバス、WebGL、エクスポート、またはWebXRのコンテキスト内で動かす必要がある；
- 可視UIがキャンバスでレンダリングされていても、アクセシビリティと自動化が依然として重要である。

## 典型的なキャンバスライブラリとの違い

ほとんどのキャンバスライブラリは描画プリミティブを提供し、レイアウト、イベント、テキスト、アクセシビリティはアプリケーションに委ねます。VectoJSは、より完全なランタイムスタックを提供します。

| レイヤー         | VectoJS                                                  | 典型的なキャンバスライブラリ |
| ---------------- | -------------------------------------------------------- | ---------------------------- |
| レイアウト       | エンティティツリーとレイアウトヘルパー                   | 手動                         |
| Hit-testing      | エンティティごとのヒットテストと変換の変換               | 手動                         |
| イベント         | DOMライクなキャプチャフェーズとバブルフェーズ            | 手動/コールバックのみ        |
| アクセシビリティ | 対象エンティティへのセマンティックDOM投影                | 通常は不在                   |
| テキスト         | レイアウトエンジン、折り返し、BiDi、アラビア語、MSDFパス | 多くの場合`fillText`のみ     |
| コンポーネント   | フォーム、オーバーレイ、markdown、スクロール、レイアウト | 通常はアプリ定義             |
| エクスポート     | 固定ステップの動画エクスポーター                         | 通常は外部                   |

## VectoJSが引き換えに手放すもの

VectoJSはCSSの利便性を、明示的な制御と引き換えにします。レイアウトとインタラクションのモデルの多くを、あなた自身が所有することになります：

- CSSは個々のキャンバスエンティティを配置しません。
- 任意のレンダリング済みテキストに対するネイティブなテキスト選択は自動ではありません。
- SEOクローラーは、キャンバスでレンダリングされたコンテンツをページテキストとして認識しません。
- アクセシビリティは投影によって有効化されますが、それでも正しいラベル、ロール、キーボード動作、コントラスト、支援技術によるテストが必要です。
- エンティティのトラバーサル、更新、セマンティック同期、アプリの計算は依然としてCPUを消費します。キャンバスがすべての処理を無料にするわけではありません。

## VectoJSを使うべきでないとき

次のような場合、まずVectoJSに手を伸ばすべきではありません：

- ブログ、マーケティングページ、ドキュメントサイト、またはCMSページを構築している；
- UIがほとんど通常のフォームとテーブルである；
- レンダリングされたコンテンツのSEO可視性が必須要件である；
- ネイティブなブラウザのテキスト選択が製品の中心である；
- カスタムなレイアウト計算、アニメーションの密度、グラフ、ゲーム、シミュレーション、または高エンティティのシーンが存在しない。

VectoJSは、レイアウト、イベント、テキスト、アクセシビリティ、エクスポートを自前で作り直すことを避けられるだけの十分なランタイム基盤とともに、**キャンバスレベルの視覚的制御**が必要なときに真価を発揮します。
