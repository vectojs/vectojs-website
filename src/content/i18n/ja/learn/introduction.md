# VectoJS入門

**VectoJS**は、視覚的またはインタラクティブな複雑さが「1つのDOM要素につき1つのもの」というモデルに収まらないインターフェース向けの、canvas-nativeなUIランタイムです。可視ツリーをJavaScriptのエンティティグラフ——**Virtual Math Tree**——として保持し、その結果をキャンバスベースのレイヤーに描画します。

インタラクティブなコンポーネントは、キャンバスの上に実際のセマンティックDOMノード（`<button>`、`<input>`、`<a>`など）を投影できます。この投影こそが、VectoJSのコントロールをアクセシブルに保ち、ネイティブ入力に対応させ、ロールベースの自動化を通じてテスト可能にするものです。

## 手短に言うと

次のようなものが必要なときにVectoJSを使ってください：

- 何千ものスタイル付きDOMノードを使わずに、何千もの視覚的エンティティを扱いたい；
- 精密な変換、曲線、hit-testing、数学的レイアウトが欲しい；
- ロールベースのアクセシビリティと自動化を備えたキャンバス規模のビジュアルが欲しい；
- 大量データ、ストリーミングUI、ゲーム、ダイアグラム、WebXRパネルを扱いたい；
- テスト、シミュレーション、動画エクスポートのための決定論的なステップ実行が欲しい。

ドキュメント優先のサイト、SEO重視の文章、通常のフォーム、あるいはカスタムなレイアウト計算を必要としないUIを構築しているときは、通常のHTML/CSSを選んでください。

## パッケージマップ

| パッケージ                | 目的                                                                                                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@vectojs/core`           | `Scene`、`Entity`、レンダラー、イベント、hit-testing、a11y投影。下記のエンジンに依存し再エクスポートするため、すべてを`@vectojs/core`からインポートできます。 |
| `@vectojs/text`           | スタンドアロンのテキストシェイピングプリミティブ：BiDi解決、アラビア語シェイピング、CSS互換のタイポグラフィ、MSDFフォント、prepared content grid              |
| `@vectojs/layout`         | スタンドアロンのレイアウトエンジン：行分割、BiDi対応のインラインレイアウト、除外フロー、オフスレッドのレイアウトワーカー                                      |
| `@vectojs/math`           | スタンドアロンの空間/物理数学：`SpatialHashGrid`のブロードフェーズと`SpringPhysics`                                                                           |
| `@vectojs/animation`      | スタンドアロンのイージングライブラリと`TweenDriver`・`SpringDriver`の値ドライバー                                                                             |
| `@vectojs/ui`             | 高レベルコンポーネント：`Button`、`Input`、`Toggle`、`ScrollView`、`Dropdown`、`Table`、その他。ランタイム依存ゼロ。                                          |
| `@vectojs/markdown`       | `Markdown` + `CodeBlock`エンティティ（`marked`でパースし、TeX数式を`@vectojs/tex`でレンダリング）、`@vectojs/ui`の上に構築                                    |
| `@vectojs/three`          | VectoJSシーンをThree.jsのテクスチャに投影し、レイキャスト入力を2Dへ戻してルーティングする                                                                     |
| `@vectojs/devtools`       | ページ内のVirtual Math Treeインスペクター：エンティティツリー、クリックで選択、ジオメトリのライブ表示                                                         |
| `@vectojs/graph3d`        | 3Dフォースディレクテッドグラフの可視化（インスタンス化されたThree.jsレンダラー）                                                                              |
| `@vectojs/video-exporter` | VectoJSシーン向けの固定ステップChromium + FFmpeg H.264エクスポート                                                                                            |

layout、text、math、animationの各エンジンは、シーングラフランタイムなしで利用できるよう、それぞれ独立したパッケージとして公開されています。`@vectojs/core`はそれらすべてに依存し再エクスポートするため、既存の`import { … } from '@vectojs/core'`のコードはそのまま動作し続けます——依存の範囲を小さく抑えたいときにのみ、スタンドアロンのパッケージに手を伸ばしてください。

## メンタルモデル

VectoJSはReactの代替品ではなく、ECSでもなく、ゼロアロケーションを主張するものでもありません。それは保持モード（retained-mode）のキャンバスUIランタイムです：

1. アプリケーション状態がエンティティを更新する；
2. エンティティがレイアウト、変換、hit-test、セマンティクスを計算する；
3. ダーティなシーンが選択されたバックエンドを通じてレンダリングされる；
4. 投影されたDOMノードが、支援技術やエージェントにインタラクティブな面を公開する。
